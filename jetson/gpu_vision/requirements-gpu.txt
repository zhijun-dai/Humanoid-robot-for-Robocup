# GPU 版运行依赖（Jetson Orin / 桌面通用）
#
# ⚠ 不要用普通 pip 源装 torch（aarch64 无 CUDA wheel）。
# Jetson 安装：
#   1) torch: NVIDIA JetPack wheelhouse，按板子 JetPack 小版本选目录
#      例 JetPack 6.1: pip install torch --index-url \
#          https://developer.download.nvidia.com/compute/redist/jp/v61/pytorch
#      （6.0→v60、6.2→v612 等，见
#       https://docs.nvidia.com/deeplearning/frameworks/install-pytorch-jetson-platform/）
#   2) torchvision 同源 wheelhouse
#   3) OpenCV: 先跑 probe.py 检查系统自带是否带 CUDA
#      （python3 -c "import cv2; print(cv2.cuda.getCudaEnabledDeviceCount())"）
#      不带则 sudo apt install python3-opencv（JetPack 源通常为 CUDA 编译）
#      或源码自编译（-DWITH_CUDA=ON, CUDA_ARCH_BIN=8.7）
#
# 桌面 CPU 验证环境：照用仓库根 requirements.txt（opencv-python + CPU torch），
# gpu_vision 自动走 CPU 回退，输出与 CPU 版一致。
