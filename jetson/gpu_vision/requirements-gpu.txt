# ── Jetson JetPack 7.2（实测路线，2026-06 NVIDIA 论坛验证）──
# 系统: Ubuntu 24.04 + Python 3.12 + CUDA 13.2。

#       改用上游 PyTorch 官方 cu132 aarch64 wheel。
#
#   python3 -m venv ~/robocup-venv && source ~/robocup-venv/bin/activate
#   pip install "numpy<=1.26.4"          # torch cu132 wheel 与 numpy 2.x 冲突
#   pip install torch==2.12.0+cu132 --index-url https://download.pytorch.org/whl/cu132
#   pip install pyserial
#   # OpenCV: 先探测预装版是否带 CUDA
#   #   python3 -c "import cv2; print(cv2.cuda.getCudaEnabledDeviceCount())"
#   # 不带 → 用 JetPack 预装或 4.8.x 带 CUDA wheel（pip 的 opencv-python 5.0 有坑）
#
# ── Jetson JetPack 6.x（旧）──
#   pip install torch --index-url \
#     https://developer.download.nvidia.com/compute/redist/jp/v61/pytorch   # 按小版本
#
# 桌面 CPU 验证环境：照用仓库根 requirements.txt（opencv-python + CPU torch），
